# LearnCraft API Overview

## Auth

- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/logout`
- `GET /auth/me`

## Content

- `GET /api/content/catalog`
- `GET /api/system/status`
- `GET /api/sync/queue`

## Notes

- `GET /notes`
- `POST /api/notes`
- `PUT /api/notes/<client_id>`
- `DELETE /api/notes/<client_id>`
